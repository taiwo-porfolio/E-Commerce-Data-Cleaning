 E-Commerce Data Cleaning Using Microsoft Excel

 Project Overview

This project focuses on cleaning and preparing an e-commerce sales dataset for further analysis. The objective was to improve data quality, consistency, and reliability by identifying and correcting issues within the raw dataset.

The cleaned dataset serves as the foundation for subsequent data analysis, descriptive statistics, exploratory data analysis (EDA), and dashboard development.

 Project Objective

The main objectives of this project were to:

- Inspect and understand the structure of the raw dataset.
- Identify and remove duplicate records.
- Check for missing and blank values.
- Correct data formatting and data type issues.
- Standardize date-related information.
- Validate numerical fields.
- Create additional date fields such as Year, Month, and Quarter.
- Prepare a clean dataset for further analysis and visualization.

  Data Cleaning Process

The following data cleaning steps were performed using Microsoft Excel:

1. Reviewed the raw dataset to understand its structure and columns.
2. Checked the dataset for duplicate records.
3. Identified blank and missing values.
4. Removed unnecessary blank records and addressed missing values where appropriate.
5. Standardized date formats.
6. Corrected formatting issues in the Year and Month columns.
7. Checked numerical fields such as Quantity, UnitPrice, and TotalPrice.
8. Reviewed product and categorical fields for inconsistencies.
9. Validated calculated sales values to ensure data accuracy.
10. Created additional fields including Year, Month, and Quarter.
11. Performed a final quality check to ensure the dataset was clean and ready for analysis.
